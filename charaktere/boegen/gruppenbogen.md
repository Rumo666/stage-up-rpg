# STAGE UP! – Gruppenbogen

> **Entwurfsstatus:** spielbarer Entwurf auf Grundlage der Systembibel v0.1<br>
> **Verwendung:** ein gemeinsamer Bogen für die gesamte Idol-Gruppe<br>
> **Wichtig:** Bereiche mit einer Abenteuerangabe bleiben bis zu ihrer
> Freischaltung leer.

Dieser Bogen hält gemeinsame Entscheidungen fest, ohne sie der Gruppe
vorzugeben. Füllt ihn im Gespräch aus. Eine Antwort darf später wachsen, wenn die
Figuren sich und ihre gemeinsame Richtung besser kennenlernen.

### Unser Satz

Vervollständigt gemeinsam:

> Wenn wir zusammen auf der Bühne stehen, möchten wir _________________________
> ____________________________________________________________________________.

Der Satz ist eine Richtung, kein Vertrag. Er darf sich im Verlauf der Kampagne
verändern.

## Mitglieder

Aurora Entertainment plant als Ausgangspunkt mit fünf Idols. Zwei oder drei
davon sind normalerweise Hauptfiguren; die übrigen sind unterstützende
Begleitfiguren. Eine kleinere oder größere Gruppe ist ebenfalls möglich.

Szene erhalten, in der ihr Beitrag wichtig wird. Doppelte Rollen sind erlaubt.

## Was uns verbindet

Beantwortet jede Frage mit einem Stichpunkt:

| Frage | Unsere Antwort |
|---|---|
| Was möchten wir gemeinsam erreichen? | |
| Was macht uns anders als andere Gruppen? | |
| Was tun wir in einer guten Trainingspause? | |
| Woran merken wir, dass jemand Unterstützung braucht? | |
| Welche kleine Sache führt bei uns leicht zu Diskussionen? | |
| Wie finden wir nach einem Streit wieder zusammen? | |

Die Antworten beschreiben Spielangebote. Sie zwingen keine Hauptfigur zu einem
Gefühl oder einer Entscheidung.

## Unser Anfang bei Aurora Entertainment

Aurora Entertainment ist eine kleine, ehrgeizige Agentur in Seoul. Sie sucht eine
Gruppe mit eigener Persönlichkeit, muss aber zugleich wirtschaftlich denken.

| Ausgangsfrage | Unsere Antwort |
|---|---|
| Warum hat Aurora gerade uns zusammengebracht? | |
| Worauf hofft die Agentur bei unserer Gruppe? | |
| Was möchten wir selbst mitgestalten? | |
| Welcher Ort in der Aurora Academy ist schon jetzt „unser“ Ort? | |

Mögliche Orte sind Trainingsraum, kleines Tonstudio, Aufenthaltsraum,
Kostümlager oder einfache Probebühne. Die Antworten dürfen Forderungen und
Reibung erzeugen, machen die Agentur aber nicht zu einem finsteren Gegner.

## Absprachen für unsere Serie

Tragt nur ein, was alle am Tisch offen festhalten möchten. Persönliche Grenzen
müssen nicht auf diesem Bogen begründet oder dokumentiert werden.

Person darf eine Szene ohne Begründung weniger intensiv erzählen, beenden,
wechseln oder ausblenden lassen.

# Spielleitungshandbuch

> **Entwurfsstatus:** vollständige Spielleitungshilfe für Playtests auf Grundlage
> der Systembibel v0.1<br>
> **Zweck:** Regeln auffinden, Folgen vorbereiten und sicher durch Wendungen führen

Dieses Handbuch ersetzt weder die Systembibel noch die Abenteuertexte. Es bündelt
die wiederkehrenden Entscheidungen der Spielleitung und verweist für genaue
Freischaltungen auf die Regelkarten.

## 1. Vor der ersten Folge

### Gemeinsam festlegen

- Girlgroup, Boygroup oder gemischte Gruppe,
- Alter, Identitäten, Rollen und Gruppenkonzept,
- gewünschter Anteil von Karriere, Freundschaft und freiwilliger Romanze,
- Intensität von mildem Mobbing, Gerüchten und Agenturdruck,
- Themen, die ausgeblendet oder gar nicht verwendet werden.

Erkläre **Grün**, **Gelb** und **Rot**. Eine Begründung ist nie erforderlich. Eine
Szene kann reduziert, abgekürzt, gewechselt, beendet oder ausgeblendet werden.

Verwendet die [Charaktererschaffung](../starter/charaktererschaffung.md) oder die
[Schnellstartgruppe NOVA](../../charaktere/schnellstart/gruppe_nova.md). Füllt den
[Gruppenbogen](../../charaktere/boegen/gruppenbogen.md) nur in den bereits
freigeschalteten Bereichen aus.

## 2. Eine Probe leiten

Würfle nur, wenn Ausgang und Folge interessant sind.

1. Frage nach Ziel und Vorgehen der Hauptfigur.
2. Wählt eine passende freigeschaltete Fähigkeit.
3. Nenne Zielwert und mindestens eine mögliche Folge vor dem Wurf.
4. Kläre günstigen oder ungünstigen Umstand.
5. Würfle Fähigkeitswürfel plus Herzwürfel W6 und freigeschaltete Zusatzwürfel.
6. Erzähle Erfolg, Glanzmoment oder Wendung als nächste Bewegung der Geschichte.

| Zielwert | sinnvoller Einsatz |
|---:|---|
| 7 | normale Herausforderung unter Druck |
| 9 | anspruchsvolle oder freiwillig riskantere Handlung |
| 11 | schwierig; meist mit Vorbereitung oder Teamwork |
| 13 | außergewöhnlich; seltene Höhepunkte statt Routine |

Einfache Handlungen gelingen automatisch. Ein hoher Zielwert dient nicht dazu,
eine notwendige Information oder den Kampagnenfortgang zu versperren.

## 3. Wendungen vorbereiten

Eine gute Wendung beantwortet drei Fragen:

- Was verändert sich jetzt sichtbar?
- Welche echte Entscheidung bleibt bei den Hauptfiguren?
- Wie geht die Geschichte trotzdem weiter?

### Schnelle Wendungen

| Bereich | mögliche Folge |
|---|---|
| Training | vereinfachen, neu ansetzen oder einen Fehler sichtbar machen |
| Zeit | eine Priorität wählen oder einen späteren Termin verändern |
| Beziehungen | Rückfrage, Missverständnis oder ehrliches Gespräch anbieten |
| Bühne | Position, Einsatz, Technik oder Publikumsreaktion verändern |
| Medien | verkürzte Aussage, zusätzliche Frage oder Grenze nötig |
| Planung | einen Bereich bewusst klein halten oder Ressource verschieben |
| Reise | Plan B, Pause oder unerwartete lokale Gelegenheit |

Biete möglichst zwei Folgen an. Gib nie Energieverlust, Stress oder einen
sinkenden Gruppenwert automatisch, wenn eine gleichwertige erzählerische Folge
passt. Vorläufige Zahlenänderungen brauchen einen klaren Anlass.

## 4. Spotlight sichern

Notiere vor jeder Folge je Hauptfigur:

| Hauptfigur | persönliche Szene | wichtige Entscheidung | Beitrag zum Finale |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

Prüfe während des Spiels:

- Wer hat zuletzt eine Entscheidung getroffen?
- Wer wurde unterstützt, aber noch nicht selbst aktiv?
- Wessen Haken, Herz oder Ziel wurde noch nicht berührt?
- Hat eine Begleitfigur gerade mehr Information oder Handlungsmacht als nötig?

Spotlight muss kein Solo sein. Ein Übergang, eine Grenze, eine kreative Auswahl
oder bewusst geschaffener Raum kann ebenso bedeutsam sein.

## 5. Begleitfiguren führen

Jede wiederkehrende Begleitfigur braucht höchstens:

- einen Wunsch,
- eine kleine Reibung,
- ein Angebot an die Hauptfiguren,
- eine Grenze dessen, was sie nie entscheidet.

Begleitfiguren können Hinweise, Gefühle und unfertige Ideen liefern. Sie lösen
kein zentrales Problem, stimmen nicht für die Gruppe und benennen Gefühle einer
Hauptfigur nicht als Tatsache. Nutze bei Bedarf die
[Begleitfiguren-Bausteine](../../charaktere/begleitfiguren/bausteine.md).

fehlende Regelgruppe vor ihrem ersten bedeutsamen Einsatz sicher ein.

## 7. Offene Playtest-Werte

Nicht als endgültig behandeln:

- Verteilung der Fähigkeitswürfel,
- Stärke von Unterstützung und Flow,
- 5 Energie und Stress 0–6,
- Entwicklungsgeschwindigkeit,
- Hype-, Bekanntheits- und Fan-Skalen,
- Budget-, Zeit- und Reisewerte,
- Dauer mit zwei gegenüber drei Hauptfiguren.

Verändere während eines laufenden Tests möglichst nur einen Wert. Dokumentiere
Anlass, alte Regel, neue Testregel und beobachtete Wirkung im passenden
Playtest-Protokoll.

## 8. Eine Folge vorbereiten

### Zehn-Minuten-Vorbereitung

1. Lies Szenenübersicht, neue Regel und Sicherheitscheck.
2. Notiere Karriere-, Herz- und Geheimnisfaden.
3. Plane je Hauptfigur einen wichtigen Beitrag.
4. Wähle zwei passende Wendungen und einen Plan B für das Finale.
5. Lege Regelkarte und Handouts bereit.

### Während der Folge

- Frage statt vorzugeben.
- Sage Zielwerte und Folgen vor Würfen an.
- Wechsle Spotlight nach Entscheidungen, nicht nur nach Zeit.
- Nutze Gelb oder Rot sofort und ohne Diskussion.
- Kürze Nebenszenen, nie die Entscheidung einer Hauptfigur.

### Nach der Folge

- markiert Entwicklung,
- aktualisiert nur freigeschaltete Gruppenwerte,
- notiert einen abgeschlossenen und einen offenen Faden,
- füllt das Playtest-Protokoll gemeinsam in wenigen Minuten aus,
- ändert keine vorläufige Regel ohne dokumentierten Anlass.

## 9. Nach der Lernkampagne

Verwendet die [Hilfe zur freien Kampagne](freie_kampagne.md). Plant zunächst eine
Folge oder drei miteinander verbundene Folgen. Wählt nur Regelbereiche, die den
aktuellen Karriere-, Herz- und Geheimnisfäden dienen.

Die Grundsätze bleiben gleich: Druck ist lösbar, Wendungen halten die Geschichte
in Bewegung, Beziehungen bleiben freiwillig, Begleitfiguren unterstützen und
alle Hauptfiguren erhalten Spotlight.
